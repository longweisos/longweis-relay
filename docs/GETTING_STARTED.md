# Getting Started with Longweis Relay

Longweis Relay is currently a macOS private beta for long-running AI workflows.

## 1. Request beta access

Start at [relay.longweisos.com](https://relay.longweisos.com/). Submit your beta request and use the account flow provided there.

## 2. Install after approval

When your beta access is approved, follow the installation instructions provided with your enrollment. Keep your Relay app updated so you receive the latest reliability and compatibility improvements.

## 3. Connect a compatible workflow

Relay is available through its General API for compatible AI tooling and runtimes.

Choose the integration that matches the workflow you already use. You do not need to change how you describe your work; Relay is designed to support longer, ongoing tasks.

## 4. Start with a real workflow

The best first test is a normal task that involves several steps, working context, or follow-up turns. Begin with a low-risk workflow, then expand once you are comfortable with the result.

## Need help?

For beta access, setup questions, or product support, email [longweis.app@gmail.com](mailto:longweis.app@gmail.com).

## Beta note

Private beta means the product is still being refined using real-world feedback. Availability, supported integrations, and behavior can evolve as we improve reliability and compatibility.
