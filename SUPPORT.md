# Support

For ordinary public-client setup questions, open a GitHub issue after running:

```bash
relay-client --version
relay-client doctor
relay-client egress
```

Share only secret-free output. Do not include account keys, premium-provider
keys, local API keys, customer content, private prompts, or private task details.

For suspected vulnerabilities, privacy concerns, billing disputes, refunds,
commercial terms, media requests, or uncertain product facts, do not use a
public issue. Contact `longweis.app@gmail.com`.

The public repository covers the local client and public protocol. It does not
provide support for the hosted implementation, private routing, or internal
operations.
